Backoffice: Sales Execution &gt; Order
Description: 
Develop the Order menu in the Backoffice (COMPASS) under the menu tree Sales Execution &gt; Order. This menu lets authorized Backoffice users view and monitor the orders submitted by Store Leaders (and other enabled frontliners) from the SFM Mobile taking-order flows (Direct Sales and Consignment). Users can search and filter the order list, open an order to view its header and line items, monitor the order status through its lifecycle (including the SAP integration status), retry sending an order to SAP when it failed or is still pending, view the SFM/SO/DO reference numbers, and export the order data.
The menu reflects the existing SFM Order List and View Delivery Order pages, adapted into COMPASS, with added summary metrics and without the Activate BCP capability.
Objective: 
[ListParagraph] • Provide an Order menu in COMPASS under Sales Execution &gt; Order for authorized Backoffice users.
[ListParagraph] • Allow users to view and monitor orders submitted by Store Leaders via the SFM Mobile app.
[ListParagraph] • Provide filters and search to make it easy to find specific orders.
[ListParagraph] • Display order status across the full lifecycle, including SAP integration status.
[ListParagraph] • Display SFM reference number, SAP SO number, and SAP DO number where available.
[ListParagraph] • Allow retrying the send-to-SAP for orders that are failed or still pending (push to SAP).
[ListParagraph] • Provide summary metrics of orders by status, including counts and total amounts, defaulting to a Month-to-Date (MTD) filter.
[ListParagraph] • Provide export of order data based on the current filter.
[ListParagraph] • Apply access control and data access restriction consistent with the Backoffice.
[ListParagraph] • Exclude the Activate BCP capability from this menu.
User/System Flow: Source: existing SFM Order List and View Delivery Order pages (to be delivered in COMPASS under Sales Execution &gt; Order).
