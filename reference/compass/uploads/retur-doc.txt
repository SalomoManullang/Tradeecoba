[ListParagraph] • If the Return Detail page has been open for an extended period and the underlying record has changed (e.g., another approver acted on it), the system must display: 'This record has been updated. Please refresh to see the latest data.'
Unauthorized Access
[ListParagraph] • Unauthorized access attempts must return a clear unauthorized error page — not a blank or broken page.
